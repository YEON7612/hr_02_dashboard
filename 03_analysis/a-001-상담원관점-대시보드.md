## 개요

[[q-009-직원만족도-고객경험]]의 분석 결과(eNPS, 번아웃×CSAT, 교육이수 비교)를 팀별로 인터랙티브하게 다시 계산해서 볼 수 있는 Streamlit 대시보드.

## 구성

- 파일: `app_agents.py` (프로젝트 루트, `app.py`와는 독립된 별도 대시보드)
- 실행: `streamlit run app_agents.py`
- 상단 팀 선택(전체/1팀/2팀/3팀)에 따라 아래 3개 차트를 BigQuery에서 직접 재계산해서 다시 그림
  - eNPS 스코어카드 — `charts/07_plotly_직원만족도eNPS스코어카드.py`의 계산 로직 재사용
  - 번아웃 x CSAT 산점도 — `charts/08_plotly_번아웃CSAT산점도.py`의 계산 로직 재사용
  - 교육 이수 여부(Y/N) 비교 — `charts/09_plotly_교육이수비교.py`의 계산 로직 재사용
- 팀 필터 시 표본이 6~7명으로 [[CLAUDE]]의 분석 기준(30건 미만은 참고용)에 못 미쳐, 화면에 경고 캡션을 표시함

## 데이터 소스

BigQuery `PROJECT1_DAY.agents01` ⋈ `project1_day_03.consultations_table` ⋈ `project1_day_03.satisfaction_table`을 직접 조인해서 매번 재계산한다(사전 계산된 표를 재사용하지 않음). 실행 전 `gcloud auth application-default login` 인증이 필요하다.
